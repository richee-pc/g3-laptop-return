# 졸업 고3 노트북 회수 체크

담임 선생님들이 반별로 노트북 대여 여부와 반납 품목(노트북 · 어댑터 · 케이블)을 체크하고, 전체 현황을 함께 보는 웹 페이지입니다.

- 화면: GitHub Pages (이 저장소)
- 저장: 구글 스프레드시트 + Apps Script 웹 앱
- 접근: 담임 공용 비밀번호 (Apps Script 스크립트 속성 `PASSCODE`)

**이 저장소에는 학생 명단이 없습니다.** 명단과 체크 결과는 담당 교사의 구글 시트에만 저장됩니다. 공개 저장소이므로 학생·교사 이름, 비밀번호를 커밋하지 마세요.

## 설정 순서

1. 구글 시트 「고3 노트북 회수 체크 (2026)」를 엽니다. (시트 이름: `명단`)
2. 메뉴 **확장 프로그램 → Apps Script** 에서 기본 코드를 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여 넣고 저장합니다.
3. 왼쪽 **⚙ 프로젝트 설정 → 스크립트 속성 → 속성 추가**: 속성 `PASSCODE`, 값 = 담임 공용 비밀번호.
4. **배포 → 새 배포 → 유형 선택(⚙) → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - 처음 배포할 때 권한 승인 창이 뜨면 본인 계정으로 허용합니다.
5. 발급된 웹 앱 URL(`https://script.google.com/macros/s/…/exec`)을 [`config.js`](config.js)의 `API_URL`에 넣고 커밋합니다.

Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 반영됩니다. (URL은 그대로 유지됩니다.)
